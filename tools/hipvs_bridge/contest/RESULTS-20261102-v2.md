# AMD V5 revision 2: public implementation summary

The implementation content matches the independently measured source
`16433ab78c539466b7123e1d3f6673cac41812ff`, a descendant of frozen V5
`634888d9b037153fa143d2c913ba4b25503e1d62`. This branch integrates the five changed
source/test blobs and updated documentation. The complete raw measurements and
receipts for this revision remain in the private team competition repository.

Uniform parameters: graph/intermediate degree128/128, NN_DESCENT12, MULTI_CTA,
width4 and itopk at least1024. There is no dataset/dimension routing and no change
to fixed hipVS, scoring inputs, SQL, CMake or Rust. The CPU-budget correction
reads calling-thread cgroup membership and applicable ancestor limits, temporarily
limits worker affinity/task-local OpenMP threads, then restores caller settings.
Reference mechanisms and retained licensing are described in PROVENANCE.md;
reference authors' scores and evidence are not claimed as this team's results.

The four new diagnostic cases used identical reused 24b host binaries and separate
new bridges, independent processes/data directories and the same16-CPU affinity.
The host's earlier complete source build is preserved; a fresh full host rebuild
is not claimed for this revision. Build timing includes the first legal query.
